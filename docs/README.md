# 文档归档目录

本目录统一存放 twinkle 的项目文档，按生命周期分三个子目录：

| 目录 | 用途 | 何时进入 |
|---|---|---|
| `planned/` | **计划进行**：已立项、尚未开工或未完成的方案/设计 | 新想法、待拍板的设计、下一里程碑规划 |
| `in-progress/` | **正在进行**：已开工、尚未收尾的路线图/工作项 | 开始落地即从 `planned/` 移入 |
| `archived/` | **已归档**：已完成的历史决策、报告、规范、任务文档 | 完成/定稿/废止后移入，只读参考 |

## 归档规则

1. **状态流转**：`planned/` →（开工）→ `in-progress/` →（完成/废止）→ `archived/`。
2. **单一来源**：任何文档只存在于一个目录，不跨目录重复。
3. **移动保留历史**：跨目录移动用 `git mv`，保留版本历史。
4. **引用同步**：移动后同步更新所有引用该路径的文件（CLAUDE.md、ARCHITECTURE.md、README.md 等）。

## 当前分布

- `planned/` — 待实施的设计（如积分计费系统设计）。
- `in-progress/` — 正在推进的路线图（Web 控制台路线图）。
- `archived/` — 已完成的历史文档，按主题分子目录：
  - `archived/ops/` — 运维操作手册
  - `archived/security/` — 安全加固
  - `archived/design/` — 设计规范
  - `archived/tasks/` — M0-M6 里程碑任务文档
