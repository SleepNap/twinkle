# 改哪个模块能热重载

**以下五个模块已接入独立 JAR 热重载。按实际修改的文件所在模块判断。**

| 修改的模块 | 当前承载的业务 | 更新方式 |
|---|---|---|
| `game-logic` | 战斗、移动、物品、装备、任务、交易、组队、成长、恢复、外观、控制设置、奖励规则 | **能热重载** |
| `login-logic` | 登录校验、账号准入、角色名校验、建角与选角查询 | **能热重载** |
| `admin-logic` | 账号管理用例、管理接口权限映射 | **能热重载** |
| `query-logic` | 角色详情、背包、任务、技能与好友数据聚合查询 | **能热重载** |
| `coordinator-logic` | 登录时的频道选择策略 | **能热重载** |
| `core`、`bootstrap`、`net-netty`、`net-packet` | 启动、加载器、执行队列、连接与协议 | **重启** |
| `domain-game`、`plugin-api` | 共享接口、DTO、玩家/背包/地图等状态类型 | **重启**；结构变化另评估迁移 |
| `channel`、`login`、`coordinator`、`http-api` | 会话、状态持有、路由、协议适配及尚未迁出的代码 | **重启** |
| `persistence` | 数据库实体、连接、事务、存档与表结构 | **重启或数据库迁移** |
| `domain-script`、`wz-provider` | 脚本引擎、资源加载基础 | **重启** |
| `twinkle-web` | 嵌入主 JAR 的前端 | **重新构建、重启** |

**判定规则：** 只改五个 `*-logic` 模块里的实现、私有方法和辅助类，可以热重载；同时改共享接口、状态、协议或公共依赖，就需要重启。新增业务实现放进对应 `*-logic`，宿主通过稳定接口调用。

外部 JS 已支持重载；WZ XML 和动态配置只限已接入内容。外部插件的完整生命周期热重载尚未验收。

发布前可运行差异检查工具，自动列出可热更模块与宿主变化。构建、发布、重试和奖励接口见 [发布说明](LOGIC-RELEASE.md)。
