## 并发入口整改（2026-09-06）

本批为存量并发整改的第一轮，已有代码尚未全部改造。针对已迁移调用链的并发问题，没有新增玩法封包，也没有移植北斗实现。执行模型以 `ARCHITECTURE.md` 为准。

| 审查问题 | 本批修改 |
|---|---|
| Netty、Tick、断线、管理线程各自修改角色 | 每频道独立执行队列；频道 Tick 只由公共时钟唤醒；注册表分发、断线清理、管理快照和 WZ 运行态提交进入所属队列 |
| Handler/Service 重复锁角色，setter 可先赋值再等待脏标记锁 | 移除已收口入口的重复外层锁；绑定后的角色、背包、物品和任务写入口校验归属，HP/MP 在赋值前检查 |
| 同步 flush 绕过单写队列，写库期间锁住角色，新修改被旧 pending 吞掉 | 在频道内取独立快照，所有保存共用写线程；按脏版本去重和确认，失败重试同样排序 |
| 换频道读写阻塞、失败仍交接、登录可能读取尚未落库的旧档 | 会话冻结与令牌、后台 IO、提交后交接；登录等离线保存并防重入，断线后的加载结果丢弃 |
| 第二次邀请覆盖旧交易，取消后旧确认仍能提交 | 邀请一次认领双方；取消先写交易终态，断线/换线/接管/重载共用入口 |
| 同一刷怪点被同时初始化、同一死亡被多人重复认领 | 刷怪检查与创建原子执行；扣血返回唯一死亡认领结果，只有认领者推动死亡收益 |
| `id -> true` 假中断、重载后已有角色永久 STALE | 真实业务取消并检查在途登记；操作绑定版本，后续操作进入新版本，迟到旧版本回调拒绝 |
| 队列满丢断线清理、暂停标志被当成已经到达安全点 | 普通任务接入配额与清理任务区分；FIFO 保序；公共 Tick 暂停等待当前 Tick 完成，频道单独排空；进程重启先关闭所有频道接入再存档 |

回归覆盖任务串行与跨频道互等拒绝、过载清理、版本切换、真实交易中断、刷怪/死亡争用、存档单写和期间变更、外泄物品引用写入拒绝、处理器换代、失败换频道、慢存档/慢登录、防重复登录和登录中断线。新增 18 项回归：`GameExecutionTest` 4 项、`TickSafePointTest` 1 项、`ConcurrencyBoundaryTest` 10 项、`AsyncCharacterHandoffTest` 3 项，并修正原有重载/停机测试对假中断的假设。最后一组 30 项定向检查已通过（含 7 条架构规则）；完整 `verify` 结果见下方自动验证记录。不计为真实客户端联调。

| `SKILL_MACRO 0x6E` | `MACRO_SYS_DATA_INIT` | 最多五组、每组三技能；名称/技能校验，删除宏时整体替换，保留其他设置 |
| `CHANGE_QUICKSLOT 0xB7` | `QUICKSLOT_INIT` | 八个 int 键位，拒绝窄化截断；未自定义时发送客户端默认快捷栏标志 |
| `CHAR_INFO_REQUEST 0x61` | `CHAR_INFO` | 同地图有效会话的等级、职业、名声、已穿戴勋章和已完成勋章任务 |
| `MULTI_CHAT 0x77` | `MULTICHAT` | 同频道队伍聊天；收件人来自服务端队伍，客户端伪造名单无效 |
| `MESO_DROP 0x5E` | 余额更新、掉落生成/移除 | 单次 10–50000，余额/版本校验，拾取原子认领，余额上限失败保留掉落；复用两分钟过期 |

字段含义核对来源为北斗相应 Handler、`PacketCreator`、`QuickslotBinding`。初始九个基础按键布局独立选择，不复制参考项目的配置列表。操作设置保存为自有版本化快照，经过 `PlayerCharacterAssembler` 与角色事务存档一起保存和加载。

按开发期数据库规则，在三个方言的 V2 主表定义中加入可空 `control_settings` 字段，没有改动用户现有数据库。后续统一验证前，旧开发库需按项目约定重建；新库直接执行完整迁移即可。未设置该字段的角色使用基础操作布局。

本批新增六项回归，扩展队伍聊天与数据库回滚测试；定向检查覆盖设置整体拒绝/重登恢复、宏与快捷栏编码、跨地图详情拒绝、金币并发拾取及余额溢出。完整客户端场景统一验证后置。

### 第二批封包：同屏角色与动作

协议布局核对北斗的 `PacketCreator`、`AbstractMovementPacketHandler` 和表情/椅子 Handler；只读取字段含义与长度，以下编码、状态管理和测试独立实现。

| 方向 | Opcode | 已接入行为 |
|---|---|---|
| 收 | `FACE_EXPRESSION 0x33` | 基础表情 1–7；广播给同图其他角色 |
| 收 | `USE_CHAIR 0x2B` / `CANCEL_CHAIR 0x2A` | 校验 WZ 存在、持有有效椅子实例；坐下/起身，死亡或椅子移出后清理 |
| 收/发修正 | `MOVE_PLAYER 0x29 / 0xB9` | 全流验证、13 字节绝对移动片段、有符号坐标、姿态和立足点同步；相对速度不再累加成位移；版本拒绝不广播 |
| 发 | `SPAWN_PLAYER 0xA0` / `REMOVE_PLAYER_FROM_MAP 0xA1` | 等待加载完成；同图双向同步、重复确认幂等、跨地图实例隔离、迟到旧连接不删除新角色 |
| 发 | `FACIAL_EXPRESSION 0xC1` / `SHOW_CHAIR 0xC4` / `CANCEL_CHAIR 0xCD` | 表情与椅子显示、本人起身确认 |
| 发 | `SHOW_FOREIGN_EFFECT 0xC6` / `GIVE_FOREIGN_BUFF 0xC7` / `CANCEL_FOREIGN_BUFF 0xC8` | 已支持的三个自身 Buff 施放动画、远程属性及取消；后来进图补发尚未到期的 Buff |

外观共用编码器已修正：普通武器位于装备槽 11，现金武器单独编码；现金服饰覆盖对应普通槽，原装备进入遮盖列表。未实现的特殊角色数据使用空段，不把公会、宠物、婚戒、摊位标为完成。

新增 13 项自动回归，另扩展既有 Buff 测试；涵盖生成报文偏移、并发进图、连接替换、换图顺序、Buff 补发、椅子持有/期限、移动截断和版本拒绝。移动解析验证全部 23 类已知片段及每个截断边界。真实客户端录包对照仍待完成。

### 第一批：基础玩法

新增 21 项自动回归，覆盖：

- 非法/远距离传送不改变地图；频道地图运行态相互隔离。
- 并发拾取只能成功一次；背包满、地图不符时掉落仍可被合法拾取。
- 指定槽位用药；物品拆分/交换保留实例属性；购买金额溢出及容量不足不扣款。
- 商店会话、报价、NPC 距离校验。
- 任务条件、服务端击杀进度、满背包失败回滚、重复完成不重复奖励。
- AP 超额分配及跨职业 SP 拒绝；自动 AP 整体校验。
- Buff 伪造等级、魔力不足、冷却、覆盖、取消和过期。
- 无邀请/过期/换连接邀请不能加入；六人上限、队长权限和断线解散。
