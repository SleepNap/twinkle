## 使用与边界

- 构建产物为主 JAR + `logic/` 下五个业务包；这是首次底座改造，首次部署需完整升级并重启，随后兼容业务变更才走热重载。
- 未迁出的业务代码仍以所在宿主模块的更新方式为准，新增规则应放进对应业务模块。
- [发布说明](../LOGIC-RELEASE.md) 包含发布、重试、启动恢复、缓存含义和奖励接口。跨模块与跨频道不宣称全局原子发布。
