# Web 控制台后续任务

> 当前视觉真值：shadcn `radix-nova`。本文只记录仍有效的控制台工作，不把归档设计当任务来源。

## 已完成

- shadcn 风格控制台框架、登录、RBAC 与写操作审计。
- 运行概览、频道、在线玩家、账号/角色只读详情、配置、运维、API Key、能力目录、审计与任务页面。
- 账号封禁/解封、强制离线，以及角色背包、任务、技能、好友等持久化详情。
- 公共、管理、内部 API 的主版本边界、生命周期登记、自动 OpenAPI 产物与 Swagger UI 入口。

## 后续任务

1. Tool 执行记录详情页：展示 executionId、输入安全摘要、结果状态与 auditRef。
2. 任务历史持久化与集群聚合：分页、进度、取消、失败重试策略。
3. 插件运行态：先定义稳定的管理 API，再展示插件加载状态、版本和贡献点。
4. 服务指标安全投影：只暴露控制台需要的聚合指标，避免直接透出底层监控数据。
5. 高风险角色操作：传送、物品/货币调整等必须先完成权限、二次确认、幂等和审计设计。
6. 公会详情：需要先补服务端 repository/application contract，当前仅展示角色保存的关系 ID 与职位。
7. 临时封禁：必须先让登录链严格执行过期时间、时区与自动失效语义，再开放控制台操作。

## Agent 边界

内置自研 Agent 已删除。未来如恢复 Agent，只允许以 DeepSeek Harness 套壳插件接入；核心服务端只提供版本化 API、插件 SPI、最小 Scope 与审计，不再承载模型编排、会话记忆或提示词逻辑。
